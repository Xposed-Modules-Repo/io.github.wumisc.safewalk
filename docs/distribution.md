# 国内分发说明

> 结论先行：**本应用没有、也不打算上架国内应用商店。** 商店里搜不到是正常现象，
> 不是被下架，也不是被屏蔽。这份文档解释原因，以及现在应该怎么装。

## 一、搜不到的真正原因

应用只发布在 GitHub：

```
https://github.com/Xposed-Modules-Repo/io.github.wumisc.safewalk/releases
```

`Xposed-Modules-Repo` 是 LSPosed 的模块索引仓库。商店的搜索只索引**已上架应用**，
从未提交过自然搜不到。

## 二、为什么不上架

不是因为懒，是这类工具在国内商店活不下来。

| 门槛 | 现状 |
|---|---|
| APP 备案 | 2024 年起强制，未备案不得提供服务；个人开发者同样需要 |
| 软件著作权 | 多数商店强制要求 |
| 无障碍权限专项审核 | 无障碍是「抢红包 / 自动点击 / 诈骗」的高危特征，需说明用途并人工复核 |
| 后台常驻 + 悬浮窗 + 请求 root | 三项叠加，多数商店直接拒 |

同类参照：**李跳跳**因「不正当竞争」被多家商店下架并停止更新；**GKD** 至今只在
GitHub 与酷安分发。这不是能力问题，是品类决定的 —— 任何能读取他人应用界面、
能长期后台运行的软件，在商店体系里都属于高风险对象。

强行上架的后果通常不是「多一个渠道」，而是：审核被拒 → 反复整改 → 侥幸上架 →
被举报下架 → 开发者账号受影响。

## 三、实际可分发的渠道

| 渠道 | 门槛 | 适合谁 | 备注 |
|---|---|---|---|
| GitHub Release | 零 | 会翻墙/能直连的用户 | 已有，国内直连可能较慢 |
| **Obtainium** | 零 | **推荐所有人** | 装一次，之后自动跟进每次发版 |
| 酷安 | 中 | 极客用户 | 需开发者认证与应用包审核，但这是本类工具的主阵地 |
| F-Droid | 高 | 开源用户 | 需可复现构建，工程量大，暂不考虑 |
| 国内应用商店 | 极高 | — | 不建议 |

### Obtainium 具体怎么用

1. 安装 Obtainium（其本身也在 GitHub 发布）
2. 在 Obtainium 里点「添加应用」
3. 粘贴本仓库地址，或直接打开这条链接：

```
obtainium://add/https://github.com/Xposed-Modules-Repo/io.github.wumisc.safewalk
```

4. 之后每次发版，Obtainium 会检查并提示更新，不再需要手动传 APK

给长辈装的时候，这条路比任何商店都稳：装一次，后面不用管。

## 四、如果一定要上架，需要准备什么

按当前政策，最少需要：

- [ ] 企业或个体工商户主体（个人主体类目受限严重）
- [ ] 软件著作权登记证书（约 30 个工作日）
- [ ] APP 备案（工信部，需境内服务器与域名；纯本地应用也需备案主体）
- [ ] 无障碍权限使用说明：为什么需要、读取什么、不上传什么
- [ ] 隐私政策与权限清单（逐项说明用途）
- [ ] 各商店的兼容性测试报告

即使全部齐备，仍可能因「后台常驻 + 悬浮窗」被拒。这是一条投入产出比极低的路。
