# SafeWalk 核心逻辑设计文档

> 版本：v2.1  
> 更新：2026-10-30  
> 目标：零误触发（躺卧/静坐/刷手机不弹出门提醒）、低功耗（≤2W）

---

## 一、整体状态机

```
                    ┌─────────────────────────────────┐
                    │         SLEEP（深度休眠）        │
                    │  - 只注册计步器，最低功耗        │
                    │  - 收到第一步 → 唤醒            │
                    └──────────┬──────────────────────┘
                               │ 收到计步事件
                               ▼
                    ┌─────────────────────────────────┐
                    │      LIGHT_MONITOR（低功耗监测）  │
                    │  - 5秒采样一次步数窗口           │
                    │  - 累计步数 < 阈值 → 继续监测    │
                    │  - 累计步数 ≥ 阈值 → 进验证      │
                    │  - 静置 > 20秒 → 回SLEEP       │
                    └──────────┬──────────────────────┘
                               │ 步数达标
                               ▼
                    ┌─────────────────────────────────┐
                    │       VERIFYING（步态验证）      │
                    │  - 打开加速度计，采样2秒         │
                    │  - GaitDetector 判定是否真走路   │
                    │  - 验证通过 → 触发提醒           │
                    │  - 验证失败 → 回LIGHT_MONITOR   │
                    └──────────┬──────────────────────┘
                               │ 验证通过
                               ▼
                    ┌─────────────────────────────────┐
                    │     TRIGGERED（触发提醒）        │
                    │  - 按开关逐个弹通知             │
                    │  - 触发后5分钟冷却              │
                    │  - 完成后回SLEEP                │
                    └─────────────────────────────────┘
```

## 二、参数配置表

### 核心阈值

| 参数 | 值 | 说明 |
|---|---|---|
| 步数阈值 | 150 步 | 5分钟滑动窗口内累计步数，达标才进步态验证 |
| 静置重置 | 20 秒 | 超过该时长无新步数 → 判定室内停留，回待机 |
| 触发冷却 | 5 分钟 | 触发提醒后，5分钟内不重复弹 |
| 步态验证时长 | 2 秒 | 打开加速度计采样2秒，判定是否真走路 |
| 验证超时 | 6 秒 | VERIFYING 状态超过6秒没结果 → 兜底回退 |

### 步态检测参数（GaitDetector）

| 参数 | 值 | 说明 |
|---|---|---|
| 自适应窗口 | 60 样本 | 滑动窗口保留60个加速度模长样本 |
| 阈值系数 | 1.8σ | 阈值 = 均值 + 标准差 × 1.8 |
| 峰值下限 | 0.6 m/s² | 阈值最低不低于0.6，防止阈值太低 |
| 峰值上限 | 2.8 m/s² | 阈值最高不超过2.8，防止阈值太高 |
| 步频下限 | 1.4 Hz | 每分钟84步，慢走下限 |
| 步频上限 | 2.2 Hz | 每分钟132步，快走上限 |
| 步间隔稳定度 | ±180 ms | 连续3步间隔差值不超过180ms才算稳定步态 |

### 姿态判定参数

| 参数 | 值 | 说明 |
|---|---|---|
| 平躺Z轴阈值 | |gz| > 8.5 | 手机接近水平面（躺床上） |
| 平躺权重 | ×1.45 | 平躺时峰值阈值放大1.45倍，更难触发 |
| 直立判定 | |gx|>7 或 |gy|>7 | 手机竖直手持 |

### 冷却时间

| 提醒类型 | 冷却 | 说明 |
|---|---|---|
| 证件提醒 | 24 小时 | 每天最多弹1次 |
| 社交礼仪 | 每次触发都弹 | 但5分钟总冷却覆盖 |
| 夜间手电 | 每次触发都弹 | 但5分钟总冷却覆盖 |
| 久坐提醒 | 24 小时 | 每天最多弹1次 |
| 电量预警 | 1 小时 | 电量低时每小时提醒1次 |

## 三、误触发防护（五道关卡）

### 第1关：步数阈值过滤
- **规则**：5分钟滑动窗口内累计 ≥ 150 步才进入验证
- **防什么**：床上翻身偶尔计几步、刷手机晃一下
- **原理**：室内正常活动步数很少，达不到150步

### 第2关：步态验证（加速度计二次确认）
- **规则**：必须检测到连续3步、步频1.4~2.2Hz、间隔稳定（±180ms）
- **防什么**：机械振动、坐车颠簸、电梯上下、开门关门
- **原理**：真走路的步频和间隔是非常规律的，其他振动不符合

### 第3关：平躺加权
- **规则**：检测到手机平躺（Z轴>8.5）时，峰值阈值 ×1.45
- **防什么**：躺床上刷手机、翻身
- **原理**：平躺时加速度模长本来就小，再放大阈值更难触发

### 第4关：静置重置
- **规则**：超过20秒没新步数 → 直接回SLEEP，清空步数窗口
- **防什么**：之前走了一段路，现在坐下不动了
- **原理**：没有持续位移 = 没出门，不触发提醒

### 第5关：冷却机制
- **规则**：触发后5分钟冷却、证件/久坐每日只弹1次
- **防什么**：反复弹窗骚扰
- **原理**：防抖+限频，用户体验好

## 四、边界规则

### 什么情况**不会**触发出门提醒
1. 躺在床上刷短视频（步数少 + 平躺加权 + 静置快）
2. 坐在沙发上看电视（步数少 + 静置快）
3. 办公室坐着打字（步数少 + 静置快）
4. 坐车里颠簸（步频不在1.4~2.2Hz区间）
5. 电梯上下（步频不对，持续时间短）
6. 开门关门拿快递（步数少，达不到150步）

### 什么情况**会**触发出门提醒
1. 真的出门走了，连续走了几百步，步态稳定
2. 步频在1.4~2.2Hz之间（正常走路速度）
3. 手机在口袋里拿着（不是平躺状态）
4. 持续行走，中间没有长时间停顿

## 五、功耗控制

### 传感器采样策略
- **待机状态**：只开 TYPE_STEP_DETECTOR（硬件计步器，几乎不耗电）
- **监测状态**：5秒检查一次步数窗口，不额外开加速度计
- **验证状态**：临时打开加速度计2秒，验证完立刻关掉
- **总采样率**：平均下来远低于1Hz，功耗控制在2W以内

### 为什么这么省电
1. 用硬件计步器（SensorHub 独立运行，CPU休眠也能计步）
2. 大部分时间在SLEEP状态，只等计步事件
3. 加速度计只在验证阶段临时开2秒，用完就关
4. 15秒才轮询一次状态，不高频CPU唤醒

## 六、变量说明

### 运行时状态变量
| 变量 | 类型 | 说明 |
|---|---|---|
| state | State枚举 | 当前状态：SLEEP / LIGHT_MONITOR / VERIFYING |
| steps | List<Long> | 5分钟滑动窗口内的步数时间戳列表 |
| lastStepTs | Long | 最后一次收到步数的时间戳 |
| lastTriggerTs | Long | 最后一次触发提醒的时间戳 |
| lastIdRemindTs | Long | 最后一次证件提醒的时间戳 |
| lastSitRemindTs | Long | 最后一次久坐提醒的时间戳 |
| lastBatteryWarnTs | Long | 最后一次电量预警的时间戳 |
| verifyStartTs | Long | 进入VERIFYING状态的时间戳 |
| torchOn | Boolean | 手电筒当前是否开启 |

### GaitDetector 内部变量
| 变量 | 类型 | 说明 |
|---|---|---|
| gravityX/Y/Z | Float | IIR低通滤波后的重力分量 |
| magWindow | List<Float> | 60个加速度模长样本的滑动窗口 |

| peakIntervals | List<Long> | 最近3次步峰的时间间隔 |
| lastPeakTime | Long | 上一次检测到步峰的时间戳 |
| currentAttitude | PhoneAttitude枚举 | 当前姿态：UNKNOWN/LAY_FLAT/UPRIGHT/TILTED |

## 七、已知限制

1. **没有GPS**：纯传感器判定，无法区分"在家小区里散步"和"真的出门了"
2. **口袋姿态影响**：手机拿在手里和放口袋里，加速度信号特征不一样，自适应阈值会自动调整，但极端情况可能误判
3. **相机避让未实现**：后置看路的自动相机避让（检测前台app、90秒冷却）还没做
4. **XSharedPreferences 废弃警告**：LSPosed 新版 API 是 XModulePreferences，旧API还能用但有警告
5. **手电筒开关状态不持久化**：重启手机后 torchOn 状态丢失

## 八、适配注意事项

1. **作用域**：必须勾选 `android`（系统进程），不是 SystemUI
2. **权限**：需要 ACTIVITY_RECOGNITION（身体活动）+ POST_NOTIFICATIONS（通知）+ CAMERA（后置看路）
3. **Android 版本**：minSdk 30 (Android 11)，targetSdk 35
4. **ROM 兼容**：国内定制ROM后台限制多，模块跑在系统进程里不受影响
