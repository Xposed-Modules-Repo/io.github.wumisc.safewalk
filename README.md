# 安全出行 SafeWalk

> 海阔天空，勇敢去走。

以本机计算为主的**出行感知**工具：用手机自带的加速度计判断「你是不是真的在走路」，要走路才提醒，不走路不打扰。不依赖 GMS，轨迹、位置、急救信息一律不出本机。

| 项目 | 说明 |
|---|---|
| 系统 | Android 13+（minSdk 33 / compileSdk 37） |
| 形态 | 普通 App；可选挂 LSPosed 模块，作用域**只需**「系统界面（SystemUI）」 |
| 协议 | AGPL-3.0 |
| 当前版本 | 5.7.17-lx102（versionCode 139） |

## 两种运行模式（这是全文最该看的一段）

先说结论：**不装框架也能用，装了只是多一层系统界面里的能力**。很多人以为这是「必须 root 的模块」，其实核心功能一行代码都不在 SystemUI 里。

### 独立模式（无 root、无框架）

只要装上 APK、给完权限就能跑，全部在 App 自己的进程里：

- **路况小窗**：`WalkPreviewService` 自建前台服务 + `TYPE_APPLICATION_OVERLAY` 浮层 + Camera2 取后摄画面，叠在微信、地图、相机任何一个应用上面。
- **步态检测**：自家的 `GaitDetector` 直接读加速度计，做带通滤波、垂直能量占比、步频闸门，判断「这一秒到底算不算一步」。
- **行走模式设置页**：尺寸、位置、透明度、文字描边、四角摆放，全部可调。
- **提醒本体**：久坐、久走、夜间独行、低电步行、证件、社交礼仪，判定与冷却都在 App 内。
- **车祸预警与急救卡**：撞击检测弹全屏卡，60 秒无响应自动求助；急救卡二级菜单可编辑、可备份。
- **磁贴**：无步数源时它就是「路况预览」的手动开关——点一下开小窗，再点关掉；有步数源（能读计步器 + 有「身体活动」权限）时自动升格成「自动跟随步行」，与框架模式下的用法一致。
- **诊断日志**：本地写盘，你主动点「上传」才上行。

独立模式里**确实用不了**的只有三项，App 会把它们写清楚、能点的地方直接置灰：**50 步智能提醒**（判定与弹通知都在 SystemUI 钩子里跑）、**超级岛 / 焦点通知增强**（要注入才拿得到岛）、**系统 UI 适配选项**（本身就是给钩子用的开关）。其余功能实测正常，包括步态检测、行走模式、路况小窗、SOS、急救卡、日志上云。

### 框架模式（LSPosed / KernelSU + libxposed API 102）

在 LSPosed 里启用模块、作用域只勾「系统界面」即可，不需要系统框架。这一层加的是**系统级入口与展示**：

- **50 步智能提醒**：走满 50 步的判定在 SystemUI 侧做，不受 App 被后台限制影响。
- **超级岛 / 焦点通知增强**：提醒、手电、小窗状态可以进 HyperOS 超级岛。
- **系统 UI 适配**：按 HyperOS 版本选择钩子行为。
- **保活**：SystemUI 侧有存在感，App 更难被清掉。

装了框架但**没生效**是第三种状态，叫**注入失联**：模块代码在 SystemUI 进程启动时注入，覆盖安装只换了磁盘上的 APK，进程里还是旧类，表现就是「更新说明写了修 A，装上后 A 一点没变」。这种情况**重启一次系统界面**即可恢复——App 会主动提示，并且只在检测到真有框架时才提示，纯独立模式不弹这个框。

### 页面怎么分工

底部三个 tab：**首页 / 功能 / 关于**。

- **首页**回答两件事：状态和开关。最上面一条**置顶条**，左边主句（`框架模式 · 注入正常` / `框架模式 · 注入失联` / `独立模式（无框架）`）加一行细节，右边两颗按钮——`上传日志`、`重启界面`；下面一张**总开关**大卡（点整行切换），再下面是公益寻人列表（每条一张卡，标「家寻宝贝 / 宝贝寻家」，每两天整批轮换）。首页不放二级设置入口。
- **功能**页是唯一改设置的地方：依次是**智能提醒**、**行走模式**、**急救卡**，每项右侧的箭头点进去就是二级页，和以前完全一样。首页的总开关关掉后，这里的设置都保留、只是不生效。
- **关于**页放项目地址、隐私开关、诊断日志开关，顶部同样有一条置顶条——上传入口只留置顶条那颗按钮，关于页不再重复摆一行——出问题的人通常正好停在这一页，顺手就能看到状态、点上传。

置顶条三句话的判据全部现算、不缓存：

- `框架模式 · 注入正常`，细节写 `锚点 3/3 · 12 秒前 · 日志开` —— 钩子每 60 秒发一次心跳，超 150 秒没心跳就转下一种。
- `框架模式 · 注入失联`，细节写 `12 分钟无心跳，重启系统界面可恢复`。
- `独立模式（无框架）`，细节写 `日志开 · 步数正常 · 50 步提醒等 3 项不可用`，并且**「重启界面」那颗按钮直接隐藏**——没有钩子可重启，留着只会让人白点。

## 安装

**只想用 App 内的功能**：下载 APK 直接安装，按引导补权限（通知、身体活动、相机、定位、悬浮窗、电池白名单、无障碍），完事，不需要 root，也不需要装任何框架。

**想用系统界面那一层**：再在 LSPosed 里启用本模块，作用域只勾「系统界面」，然后重启一次系统界面。

```
obtainium://add/https://github.com/Xposed-Modules-Repo/io.github.wumisc.safewalk
```

本应用没有上架任何商店，商店里搜不到是正常的。隐藏桌面图标后有三条恢复路径：系统设置里「显示图标」、下拉控制中心点磁贴（图标隐藏时它就是恢复入口）、或 `adb shell am start -n io.github.wumisc.safewalk/.MainActivity`。

## 无障碍

面向视障与低视力用户做过针对性处理：路况小窗两行文字合成一句人话、整列只暴露一个无障碍节点、播报做 3 秒节流与 50 步里程碑；28 个开关与 14 个滑杆都绑定了所在行的标题，读屏不再只念「开关，已关闭」；27 处分区标题声明为 heading，可用「跳到下一个标题」掠过整页；说明文字对比度 5.15:1、可点块 48dp 起、字体放大 200% 不裁字。

## 隐私

全部计算在本机完成：不埋点，不上传轨迹、位置与急救信息。诊断日志默认只写本地，仅当你主动同意并点击「上传诊断日志」时才发送已脱敏的机型环境与最近日志，可随时撤回同意。
